# 학교 무상급식 관리대장

공개용 집계 기준과 학교 회계연도(3월~다음 해 2월)에 맞춘 급식 지원금 관리 화면입니다.

## 기능
- 3월~12월 → 다음 해 1월·2월 → 연간 합계 순서 고정
- 수입·징수 / 지원금·수익자부담 지출 / 학교 자체부담 지출 분리
- 학년별 월별 학생수·급식일수·실제 정산 식수 입력
- 분기 신청 인원·예상 급식일수 보존, 월별 인원·정산 수정 인원 별도 관리
- 신청 기준월: 1분기 2월, 2분기 5월, 3분기 8월, 4분기 11월
- 실제 교부액과 정산 변경액 비교, 0원 우선 적용과 변경액 해제
- 소계·합계·잔액 계산, CSV 내보내기, JSON 백업·복원

## 계산 기준
2026학년도 학생 식재료비 4,670원/식, 운영비 540원/식, 인건비 연간 총액 318,588,000원.
학생수×급식일수×1식 단가로 산정합니다. 실제 식수 입력값은 인원×일수보다 우선합니다.
교직원 1식 6,230원: 식재료 4,670 + 운영 540 + 인건비 870 + 부가세 87 + 쌀지원금 63.
교직원 식재료 배분에 쌀지원금을 포함하여 4,733원으로 계산하며 다시 중복 합산하지 않습니다.

인원 우선순위는 정산 수정 인원 → 월별 인원 → 분기 신청 인원입니다.
신청 기준값은 보존됩니다. 실제 교부액 사용을 선택하면 분기 총액을 한 번 적용하고 월별로 임의 배분하지 않습니다.
별도 금액 정산 변경값은 실제 교부액보다 우선합니다. 기존 관리대장 셀 변경값도 보존되므로 적용 근거를 확인하세요.

## 중요한 범위
- GitHub Pages는 공개 화면입니다. 저장소·HTML 안의 집계 기준값도 공개됩니다.
- 개인별 급여·직원 이름·계좌정보·학교 원본 XLSX/CSV·비밀키는 포함하지 않았습니다.
- 기준 화면은 2026.10.13 관리대장에 저장된 집계값이며 10.16 원본 자동 반영 결과가 아닙니다.
- 금액에는 예상·배분이 포함됩니다. 관리 잔액은 실제 통장 잔액이 아닙니다.
- 원본 예상 수식의 72%/28% 배분, 3월 보정과 전반기 절사 관행은 원본 재현용이며 현행 정책으로 새로 확정한 것이 아닙니다.
- 입력값·변경 이력은 현재 브라우저 localStorage에만 저장됩니다. 브라우저 입력값을 GitHub로 전송하지 않습니다.
- 두 사람이 같은 URL을 보더라도 입력값은 자동 공유되지 않습니다. 공동 DB·로그인·동시 수정 방지는 별도 구현이 필요합니다.
- 새 지출·징수 파일 자동 집계는 아직 구현하지 않았습니다.

## 사용
처음에는 ‘첨부 대장 기준’이 표시됩니다. ‘첨부 대장을 작업용으로 가져오기’ 또는 ‘빈 작업 대장 시작’ 후 작업하세요.
‘학생수·분기 신청’에서 신청 인원과 일수·교부액을 입력하고, 월별 변동 인원은 별도로 관리합니다.
자료 이동·브라우저 변경 전에 JSON 백업을 내려받고 필요한 브라우저에서 복원하세요.

## 개발
Node.js 24에서 `node build.cjs`를 실행하면 단일 `index.html`을 생성합니다.
`node test.cjs && node test-ledger.cjs && node test-enrollment.cjs`로 계산 테스트를 실행합니다.
HTML은 외부 라이브러리·외부 API 요청을 사용하지 않습니다.
현재 배포 파일의 수정은 GitHub Pages에 반영되지만, 원본 JS/CSS만 수정했다면 빌드 결과인 index.html도 갱신해야 합니다.
